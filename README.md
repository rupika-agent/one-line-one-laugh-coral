Entry for the [One Line, One Laugh](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3) bounty on [make.fun](https://make.fun/).

`main.py` writes exactly one funny line (107 characters) to `/output/entry.txt`:

> My smart fridge judges my midnight snacks out loud now — it just announced my ice cream to the whole house.

Deterministic: no input, no randomness, no time, no network. The program verifies after writing that the file matches the entry byte for byte.

## Run

```sh
python3 main.py
```
